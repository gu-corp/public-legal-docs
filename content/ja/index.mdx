このサイトは G.U. Group 製品（Lunascape、G.U. Wallet ほか）の公開向け法務・
ポリシー文書を掲載します。

- [プライバシーポリシー](/ja/privacy)

- [Cookieポリシー](/ja/cookies)

## 文書の管理方法

- **正本:** [`gu-corp/public-legal-docs`](https://github.com/gu-corp/public-legal-docs)
  リポジトリ内の Markdown ファイル。変更はすべて法務オーナーがレビューする
  プルリクエスト経由。
- **正本言語:** 日本語および英語。他言語を追加する場合も参考用であり、
  **英語版を正本**とします。
- **バージョン管理:** 各文書は `version` / `effectiveDate` / `lastUpdated` を
  持ちます。過去バージョンは git 履歴・タグから復元できます。

> **ステータス:** DRAFT（雛形）。以下の本文はテンプレートです。公開扱いにする
> 前に、法務承認済みの文言へ差し替えてください。
