このサイトは **G.U. Group** 製品（Lunascape、G.U. Wallet ほか）の公開向け

- [プライバシーポリシー](/privacy)

- [Cookieポリシー](/cookies)

## 文書の管理方法

- **正本:** [`gu-corp/public-legal-docs`](https://github.com/gu-corp/public-legal-docs)
  リポジトリ内の Markdown ファイル。変更はすべて法務オーナーがレビューする
  プルリクエスト経由。
- **正本言語:** 日本語および英語。他言語を追加する場合も参考用であり、
  **英語版を正本**とします。
- **バージョン管理:** git 履歴・タグにより過去の版をすべて保持します。
