# G.U.Group — Legal & Policies

This site hosts the public legal and policy documents for **G.U. Group**
products (Lunascape, G.U. Wallet, and others).

- [Privacy Policy](/privacy)
- [Terms of Service](/terms)
- [Cookie Policy](/cookies)

## How these documents are managed

- **Source of truth:** the Markdown files in the
  [`gu-corp/public-legal-docs`](https://github.com/gu-corp/public-legal-docs)
  repository. Every change is a pull request reviewed by the legal owner.
- **Authoritative languages:** English and Japanese. Other languages, if added,
  are provided for reference only — the **English version is authoritative**.
- **Versioning:** git history and tags preserve every past revision.
